# 项目代码与设计信息

## 设计来源

本项目依据《星宝家庭互助平台 V1.0 轻量化概要设计文档（修订版）》建设。该版本将原稿的“微服务解耦”调整为适合 V1.0 的“模块化单体 + 异步任务”路线，并强调以下边界：

1. 记录、学习、交流、互助是 V1.0 的四个主场景。
2. 儿童档案、诊断、量表和成长记录按敏感个人信息处理。
3. 知识内容默认使用来源索引与摘要；转载/保存必须能说明授权或许可。
4. AI 只做风险分级辅助，不输出诊断、治疗结论或替代人工审核。
5. 二手板块只做公益信息展示与线下自主沟通，不形成交易闭环。

## 代码组织

```
src/main/java/cn/xingbao
├── common       统一响应与异常处理
├── config       演示工具数据初始化
├── controller   REST API
├── domain       JPA 领域实体
├── repo         数据访问接口
└── service      风控与隐私策略
```

## 本地数据

H2 文件数据库位于运行目录 `data/xingbao.*`。测试期间可删除该目录后重新启动以重置数据；不要在生产环境使用 H2 或演示令牌。
